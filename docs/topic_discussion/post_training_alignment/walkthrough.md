# 后训练与对齐深入阅读

## 主故事线

一条完整的后训练故事，可以按下面的顺序读：

`SFT model -> preference data -> method choice -> training -> eval -> project decision`

这条线的重点不是背某个 loss，而是把“为什么还要对齐、对齐该用哪种方法、结果怎么判断”讲清楚。

## 1. 从 SFT 之后开始

先明确一个前提：

- SFT 解决的是“先会回答”
- 后训练 / 对齐解决的是“回答得更符合偏好”

所以后训练不是替代 SFT，而是在 SFT 之后继续做目标对齐。

## 2. 看方法谱系

进入 `14 / 15 / 16` 后，要分清三件事：

- PPO / RLHF 是完整但重的路线
- DPO 是更轻的偏好优化路线
- GRPO 是更偏组内比较的路线

不要把它们只看成不同名字的“对齐”。

## 3. 看数据和评测

进入 `50` 后，重点是：

- chosen / rejected 怎么构造
- group candidates 怎么来
- win-rate / pairwise accuracy / judge score 怎么对应方法

这一步决定方法训练出来的东西能不能被正确评价。

## 4. 看项目如何落地

进入 `84` 和 `85` 后，不要只看 loss。

至少要确认：

- 数据是否可信
- 训练目标是否一致
- 评测是否能说明收益
- 最后能不能输出采用建议

## 5. 回到主线位置

如果在 `09-13 + 60` 这条主线里，你已经能把 SFT / LoRA 跑通，那么后训练专题就是下一层扩展：

- 先学会“让模型学会回答”
- 再学会“让模型更符合偏好”

## 典型分支

### 分支 1：偏好对不干净

先回到 `50`，不要先改 loss 或项目页。

### 分支 2：方法选错

先回到 `14 / 15 / 16`，确认 PPO、DPO、GRPO 的边界。

### 分支 3：项目结果说不清

先回到 `84 / 85`，看评测口径是否和数据对齐。

## 阅读建议

1. 先从 `14 -> 15 -> 16` 看方法谱系。
2. 再看 `50` 补数据和评测口径。
3. 然后看 `84 -> 85` 看如何落成项目。
4. 最后回到 `60` 和 `13`，把它和训练微调主线的边界分清。
